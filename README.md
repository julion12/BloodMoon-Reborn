# BloodMoon-Reborn

Modernized version of the original BloodMoon plugin by SpectralMemories.

BloodMoon-Reborn brings the classic BloodMoon gameplay experience to modern Minecraft servers running Paper and Purpur.

## Features

* BloodMoon events during the night
* Increased mob difficulty
* Customizable mob attributes
* Boss mob support
* Reward system
* Multi-world support
* WorldGuard support
* Fully configurable
* Modern Paper/Purpur compatibility

---

## Compatibility

### Supported Minecraft Versions

* 1.21+
* Paper
* Purpur

### Java Version

* Java 21

---

## Installation

1. Download the latest release.
2. Place `bloodmoon.jar` inside your server's `plugins` folder.
3. Start the server.
4. Configure the plugin files generated inside:

```text
plugins/BloodMoon/
```

5. Restart or reload the server.

---

## Commands

| Command                    | Description                                |
| -------------------------- | ------------------------------------------ |
| /bloodmoon show            | Shows information about the next BloodMoon |
| /bloodmoon start           | Starts a BloodMoon                         |
| /bloodmoon stop            | Stops a BloodMoon                          |
| /bloodmoon reload          | Reloads the configuration                  |
| /bloodmoon spawnzombieboss | Spawns the Zombie Boss                     |
| /bloodmoon killbosses      | Removes active bosses                      |

---

## Permissions

| Permission                | Description                |
| ------------------------- | -------------------------- |
| bloodmoon.bloodmoon       | Base command permission    |
| bloodmoon.show            | View BloodMoon information |
| bloodmoon.start           | Start BloodMoon            |
| bloodmoon.stop            | Stop BloodMoon             |
| bloodmoon.reload          | Reload configuration       |
| bloodmoon.spawnzombieboss | Spawn Zombie Boss          |
| bloodmoon.killbosses      | Kill active bosses         |
