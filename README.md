# BloodMoon-Reborn

Modernized version of the original BloodMoon plugin by SpectralMemories.

## Description

BloodMoon-Reborn updates the classic BloodMoon plugin to work with modern Minecraft server software such as:

* Paper 1.21+
* Purpur 1.21+

## Features

* Blood Moon events
* Custom boss mobs
* Reward system
* Configurable settings
* WorldGuard support

## Compatibility

Tested on:

* Purpur 1.21.4
* Java 21

## Build

```bash
./gradlew build
```

The compiled JAR will be generated inside:

```text
build/libs/
```
